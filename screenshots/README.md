# Dashboard Screenshots

This folder contains UI captures of the production **FraudShield AI** dashboard:

1. `dashboard_overview.png`: Executive KPI telemetry, transaction distribution donut chart, and log-scaled monetary amount comparison.
2. `real_time_detection.png`: Single transaction parameter inputs, fraud probability scoring card, decision threshold, and instant SHAP waterfall attribution.
3. `batch_analysis.png`: CSV batch upload progress, automated risk categorization (High/Medium/Low), and CSV export.
4. `model_benchmark.png`: ROC & Precision-Recall comparison curves across Logistic Regression, Random Forest, and XGBoost, with confusion matrix.
5. `explainable_ai.png`: Global SHAP feature importance ranking and local transaction risk factor attribution with automated compliance narratives.
